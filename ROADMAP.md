# Ara Roadmap

Last updated: Q2 2026. This roadmap is reviewed and refreshed quarterly so external users and contributors can see where Ara is headed.

Ara is an agent-building agent for macOS. It helps people design, run, and refine AI agents that can work across desktop apps, browser sessions, local files, and code repositories.

## Current Focus

Our near-term focus is making agents feel dependable and native on Mac: clear task setup, visible progress, reliable desktop interaction, safe background coding workflows, and better ways to learn from each completed run.

## What's Next

Over the next few quarters, we expect to invest in:

- More reliable agent runs, including stronger recovery when an app, browser page, or coding workflow changes unexpectedly.
- Clearer background-agent lifecycle management, from task start through branch, commit, review, and cleanup.
- Better transparency for users, including richer run timelines, clearer permission boundaries, and easier ways to inspect what an agent changed.
- Deeper integrations with everyday work tools so agents can move between planning, communication, code, and deployment with less manual context-switching.
- More reusable skills, templates, and examples that help contributors build practical agents without starting from scratch.

## How to Contribute

Useful contribution areas include:

- Reliability tests and evaluations for common agent workflows.
- Documentation and examples that show complete tasks from setup to finished output.
- App and service integrations that help Ara work with more of a user's daily tools.
- macOS accessibility improvements that make desktop control more robust across apps and OS versions.

If you want to help, open an issue, look for beginner-friendly tasks, or reach out through [ara.so](https://www.ara.so).

## Update Cadence

This roadmap should be revisited once per quarter. Each update should keep the document public-facing, avoid internal-only implementation details, and explain any major direction changes in language that users and contributors can understand.
