# Ara Roadmap

Ara is an agent-building agent for macOS. It helps people design, run, and refine agents that can work across real desktop apps, browsers, repositories, and connected services.

This roadmap is intentionally public-facing. It describes product direction and contribution areas without exposing internal plans, customer details, credentials, private infrastructure, or security-sensitive implementation notes.

## Update Cadence

We review and refresh this roadmap once per quarter. Dates and priorities may change as we learn from users, contributors, and the broader agent ecosystem.

## Current Focus

We are focused on making Ara feel dependable, transparent, and native on macOS. That means smoother agent setup, clearer run status, safer desktop control, better background coding workflows, and tighter feedback loops between each agent run and the reusable skills it improves.

## What's Next

### Better agent authoring

We want it to be easier to turn a recurring workflow into an agent. Upcoming work includes clearer setup flows, reusable templates, stronger defaults, and better ways to preview what an agent will do before it runs.

### More reliable desktop and browser work

Ara's value depends on agents completing real work in real apps. We are improving how agents observe state, recover from UI changes, explain what happened, and ask for human approval only when a task genuinely needs it.

### Background coding that is easier to trust

Background agents should leave behind clean commits, reviewable pull requests, and concise summaries. We are continuing to improve isolated worktrees, validation checks, PR handoff metadata, and reviewer visibility.

### Connected knowledge and memory

Agents get better when they remember useful preferences, project conventions, and past outcomes. We are building clearer controls for what Ara remembers, how that context is reused, and how users can inspect or remove it.

### Integrations with everyday tools

We will continue expanding safe integrations with tools teams already use, including code hosts, issue trackers, documentation systems, communication apps, databases, analytics tools, and deployment platforms.

## Contribution Areas

External contributors can help most by improving documentation, writing realistic evals for agent workflows, hardening macOS accessibility behavior, building integrations, and reporting places where Ara's agent runs are confusing or brittle.

If you want to contribute, open an issue, look for public issues labeled `good first issue`, or reach out through [ara.so](https://www.ara.so).

## Transparency Principles

We aim to keep public roadmap updates useful without over-promising. Roadmap items are directional, not guaranteed release commitments. When priorities change, we will prefer updating this document over leaving stale expectations in place.
