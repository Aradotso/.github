# Contributing to Ara

Thanks for your interest in contributing! Ara is an agent-building agent for macOS, made by [Aradotso](https://ara.so).

## How to Contribute

### Reporting Bugs
Open an issue with a clear description, steps to reproduce, and your macOS + Ara version. Check existing issues first.

### Feature Requests
Use [GitHub Discussions](https://github.com/orgs/Aradotso/discussions) to propose features before filing issues.

### Pull Requests

1. Fork the relevant repo and create a feature branch (`feat/my-thing` or `fix/my-bug`).
2. Keep commits focused and atomic. Use [Conventional Commits](https://www.conventionalcommits.org/) prefixes: `feat:`, `fix:`, `docs:`, `chore:`, `ci:`.
3. Update `CHANGELOG.md` under `[Unreleased]` if your change is user-facing.
4. Open a PR against `main`. Add a description covering what changed and how to test it.
5. All PRs require one review before merge.

### Commit Message Format

```
<type>(<scope>): <short summary>

<optional body explaining the why>
```

Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`, `ci`, `perf`.

## Code of Conduct

All contributors are expected to follow our [Code of Conduct](./CODE_OF_CONDUCT.md).

## Security

To report a vulnerability, see [SECURITY.md](./SECURITY.md). Do **not** file public issues for security problems.
