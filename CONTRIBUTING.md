# Contributing to Aradotso

Welcome! We are excited that you want to contribute to Ara and the Aradotso ecosystem. Please read through these guidelines to understand how you can help build, refine, and improve automated agents.

## Code of Conduct

We expect all contributors to adhere to a welcoming, respectful, and professional standard of behavior.

## How to Contribute

1. **Find an Issue**: Browse open issues across our repositories or check the [ROADMAP.md](ROADMAP.md) for planned enhancements.
2. **Fork and Branch**: Create a feature branch from the default branch.
3. **Draft a Pull Request**: Submit your pull request as a draft early to get continuous feedback.
4. **Follow Guidelines**: Keep your changes atomic, specific, and self-contained. Ensure commits are descriptive.

## Guidelines for Building Agent Skills

When contributing skills or integrations:
- Ensure the skill is fully documented in its corresponding `SKILL.md`.
- Include a robust `Pitfalls` section detailing common failures, OS quirks, or edge cases.
- Verify that standard commands run cleanly in non-interactive mode.

Thank you for contributing to the future of agent automation!
