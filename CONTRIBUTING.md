# Contributing to Ara

Thanks for helping improve Ara projects. This repository provides the default organization profile, governance docs, license, and brand assets used as a baseline by Ara repositories.

## How to contribute

- Open focused pull requests with a clear summary and rationale.
- Keep governance changes easy to audit by separating policy edits from unrelated formatting updates.
- Preserve public-facing tone: concise, direct, and practical.
- Include screenshots or rendered previews when changing profile imagery or brand presentation.

## Development workflow

1. Create a branch from the current default branch.
2. Make the smallest useful change.
3. Validate Markdown links, image paths, and GitHub Community profile file names.
4. Commit with a clear message describing the policy or asset changed.
5. Open a pull request for review.

## Governance changes

Changes to `SECURITY.md`, `CODE_OF_CONDUCT.md`, `LEGAL.md`, `LICENSE`, and `CODEOWNERS` should be reviewed by an Ara maintainer before adoption by downstream repositories.
