## Open Source vs. Proprietary

Ara maintains a mix of open-source and proprietary repositories under the [Aradotso](https://github.com/Aradotso) and [ara-experiments](https://github.com/ara-experiments) GitHub organizations.

**Proprietary (all rights reserved)**

- `ara-cua` — the Ara desktop application and its associated back-end services
- `amp` — internal tooling and configuration
- `ara-python-sdk` — the Ara Python SDK (separate commercial license required for use in competing products)

These repositories carry a custom proprietary license. You may not copy, modify, distribute, or reverse-engineer them without prior written permission from Ara Intelligence, Inc.

**Open Source**

Selected components are released under permissive or copyleft licenses and are clearly marked in each repository's `LICENSE` file. Examples include community experiments and integrations published under MIT or Apache 2.0. The governing license for any given repository is the `LICENSE` file at its root.

When no `LICENSE` file is present, the code is proprietary by default and no rights are granted.

## Privacy and Data Handling

Ara's privacy practices are governed by the Privacy Policy published at [https://ara.so/privacy](https://ara.so/privacy).

Key points:

- Ara collects usage telemetry to improve product quality. Users can opt out in Settings.
- Workspace content (files, browser sessions, terminal output) processed by Ara agents is not used to train models or shared with third parties except as needed to fulfill the service (e.g., routing a prompt to a configured AI provider).
- Ara stores minimal user data. Authentication credentials and API keys entered by users are encrypted at rest.
- Data residency is currently US-based (AWS us-east-1 / Railway). Enterprise customers may request alternative arrangements.
- For data deletion or access requests, email privacy@ara.so.
