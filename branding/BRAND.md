# Ara Brand Guidelines

Ara is an agent-building agent for Mac. These guidelines keep Ara's identity consistent across surfaces.

---

## Logo

The Ara logo comes in two forms:

- **Icon mark** — the stylised `A` glyph inside a rounded rectangle. Use when space is tight or when Ara is already identified by context (app icons, favicons, social avatars).
- **Wordmark** — icon mark + "Ara" logotype. Use as the primary lockup in most contexts.

### Available files

| File | Use |
|------|-----|
| `logos/ara-logo-wordmark.svg` | Default (light backgrounds) |
| `logos/ara-logo-wordmark-dark.svg` | Reversed (dark backgrounds) |
| `logos/ara-icon.svg` | Icon-only mark |
| `logos/ara-logo-16x16.png` | Favicon / tiny UI |
| `logos/ara-logo-32x32.png` | Small UI / toolbar |
| `logos/ara-logo-64x64.png` | Mid-size UI / docs |
| `logos/ara-logo-256x256.png` | App icon / open-graph |
| `logos/ara-logo-512x512.png` | High-res / print |

### Minimum sizes

- Icon mark: 16 × 16 px minimum.
- Wordmark: 80 px wide minimum.

### Clear space

Maintain clear space of at least half the icon's height on all four sides of any logo variant.

### Don'ts

- Do not recolour the logo outside the approved palette.
- Do not stretch, rotate, or add drop shadows.
- Do not place the light wordmark on a light background or the dark wordmark on a dark background.
- Do not alter the letterforms or proportions.

## Colours

### Primary

| Name | HEX | RGB | Usage |
|------|-----|-----|-------|
| Ara Black | `#0F0F0F` | `rgb(15, 15, 15)` | Primary text, icon backgrounds, dark fills |
| Ara White | `#FFFFFF` | `rgb(255, 255, 255)` | Reversed text, light fills |

### UI / Accent

| Name | HEX | RGB | Usage |
|------|-----|-----|-------|
| Surface 100 | `#F5F5F5` | `rgb(245, 245, 245)` | Page backgrounds, cards |
| Surface 200 | `#E8E8E8` | `rgb(232, 232, 232)` | Borders, dividers |
| Ink 500 | `#6B6B6B` | `rgb(107, 107, 107)` | Secondary text, placeholders |
| Ink 700 | `#2E2E2E` | `rgb(46, 46, 46)` | Body text on light |
| Accent Blue | `#2563EB` | `rgb(37, 99, 235)` | Links, interactive states |
| Accent Blue Hover | `#1D4ED8` | `rgb(29, 78, 216)` | Hover / focus ring |
| Success | `#16A34A` | `rgb(22, 163, 74)` | Confirmations |
| Destructive | `#DC2626` | `rgb(220, 38, 38)` | Errors, destructive actions |

### Dark-mode equivalents

Swap Surface 100 ↔ `#111111`, Surface 200 ↔ `#1F1F1F`, Ink 700 ↔ `#E8E8E8`, Ink 500 ↔ `#888888`. Primary and accent colours remain the same.

## Typography

Ara uses the **Inter** typeface as its primary font. Fall back to `'Helvetica Neue', Helvetica, Arial, sans-serif` when Inter is unavailable.

### Scale

| Role | Size | Weight | Line height |
|------|------|--------|-------------|
| Display | 40 px / 2.5 rem | 700 | 1.1 |
| H1 | 32 px / 2 rem | 600 | 1.2 |
| H2 | 24 px / 1.5 rem | 600 | 1.3 |
| H3 | 20 px / 1.25 rem | 600 | 1.4 |
| Body | 16 px / 1 rem | 400 | 1.6 |
| Small | 14 px / 0.875 rem | 400 | 1.5 |
| Label / UI | 12 px / 0.75 rem | 500 | 1.4 |
| Code | 14 px / 0.875 rem | 400 — `'JetBrains Mono', 'Fira Code', monospace` | 1.6 |

Letter-spacing: `-0.01em` for headings; `0` for body.

## Voice & Tone

- **Concise.** Say what matters, nothing more.
- **Action-oriented.** Lead with verbs.
- **Direct.** No filler, no corporate speak.
- **Human.** Friendly but not sycophantic.
