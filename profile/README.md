## Contributing & Community

We welcome bug reports, feature requests, and code contributions across all Ara repositories.

### Reporting bugs and requesting features

Open a [GitHub Issue](https://github.com/Aradotso) in the relevant repository. Use the **Bug report** or **Feature request** template if one is available. For security issues, email [founders@ara.so](mailto:founders@ara.so) instead of filing a public issue.

### Contributing code

1. Fork the repository and create a branch from `main`. Use the format `<type>/<short-description>` — e.g. `fix/auth-token-refresh` or `feat/new-skill-loader`.
2. Make your changes. Keep commits small and focused; reference the related issue in the commit message where applicable.
3. Open a pull request against `main`. CI checks (lint, type-check, tests) must pass before a review is requested.
4. A maintainer will review your PR, leave feedback if needed, and merge once it's approved.

Please follow the coding style and conventions already in the repo you're contributing to. If you're unsure, ask in the PR description.

### Getting in touch

- **Email:** [founders@ara.so](mailto:founders@ara.so)
- **Website:** [ara.so](https://www.ara.so)

We're a small team — response times may vary, but we read everything.
