Welcome to the Aradotso GitHub organization, the home of Ara—the agent-building agent by Ara (ara.so). Ara is designed to help you build, run, and refine automated agents that can control your Mac, browse in Ara panes, execute local terminal tasks, and remember critical cross-session memories.
