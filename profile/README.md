## 🐛 Bug reports & feature requests

Found a bug or have an idea? Open a [GitHub Issue](https://github.com/Aradotso/.github/issues) in the relevant repository.
For product feedback and feature requests tracked by the team, use the [Linear](https://linear.app) board (internal team) or drop a note to **sven@ara.so**.
Critical production issues are also captured via Sentry — but GitHub Issues is the right entry point for the community.

## 🤝 Contributing code

1. Fork the repo and create a branch off `main` using the convention `<type>/<short-description>` (e.g. `fix/auth-token-refresh`, `feat/new-agent-surface`).
2. Keep commits atomic and prefix them with the component scope, e.g. `(AraDesktop) fix: …` or `(AraWeb) feat: …`.
3. Open a pull request into `main`. The PR title should follow the same `scope: description` pattern.
4. CI will run lint, type-check, and tests automatically — all checks must pass before merge.
5. At least one maintainer review is required. We aim to respond within 2 business days.
