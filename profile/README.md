Ara builds computer-using agents that help people create, operate, and improve software on their Mac. Our mission is to make every builder dramatically more capable by turning recurring workflows into reliable, learned agents.

## Repository highlights

- `ara-cua`: Ara's core monorepo for the desktop app, web surfaces, API, admin tools, infrastructure, migrations, and product documentation.
- `.github`: Organization-wide profile, governance, legal, security, contribution, and maintainer-routing baseline for public repositories.
- Public examples and templates: Lightweight resources that demonstrate how Ara agents, workflows, and integrations are structured.

## How we work

- Agents should be useful, observable, and easy to improve after every run.
- Security and privacy boundaries are product requirements, not afterthoughts.
- Repository standards should make the safe path the easiest path for contributors and maintainers.
