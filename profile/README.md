## Open-Source Projects

**[OpenAra](https://github.com/Aradotso/OpenAra)** — Open-source computer use for any agent. Drop-in CUA layer that lets any LLM agent see and control a desktop.

**[ara.engineer](https://github.com/Aradotso/ara.engineer)** — `ae`, the Ara engineer CLI. Install with `curl -fsSL https://ara.engineer/install | sh` and run AI-powered engineering tasks from the terminal.

**[coshot](https://github.com/Aradotso/coshot)** — Native macOS overlay (⌥Space) that captures a region, OCRs it, and pastes the result via Cerebras in under 1.5 s at ~460 KB.

**[ara-python-sdk](https://github.com/Aradotso/ara-python-sdk)** — Python SDK for building on top of the Ara platform.

**[.github](https://github.com/Aradotso/.github)** — This org profile repo (amp). Contributions and corrections welcome.
