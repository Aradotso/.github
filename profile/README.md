## Mission

Ara builds agentic computing infrastructure for people who want AI to do real work on their Mac, across the browser, terminal, codebase, and everyday apps. Our mission is to make trustworthy automated agents feel native, observable, and useful from the first run.

## Governance baseline

This organization profile establishes Ara's foundation release: proprietary licensing, security reporting, contribution expectations, community standards, and code ownership. Repository-specific documents may add stricter requirements, but they should not weaken this baseline without maintainer approval.
