## What Ara Does

Ara is a Mac-native agent-building platform. It lets you create, run, and refine automated agents that control your desktop, browser, terminal, and the apps you already use — without leaving your workflow.

**Key capabilities**

- Run background coding agents inside isolated git worktrees
- Control your Mac screen, keyboard, and mouse via computer use
- Browse and interact with web pages inside Ara surfaces
- Connect to Linear, Stripe, Supabase, Axiom, and more via Brain plugins
- Persistent memory and skill library that improves across sessions
