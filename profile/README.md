## Built With

Ara is built across a handful of tightly integrated services and frameworks. Here's the core stack:

| Layer | Technology |
|---|---|
| Web app | [Next.js](https://nextjs.org) · [React 19](https://react.dev) · [Tailwind CSS v4](https://tailwindcss.com) |
| Backend / APIs | [Bun](https://bun.sh) · [Hono](https://hono.dev) |
| Database & auth | [Supabase](https://supabase.com) (Postgres + Auth + Realtime) |
| Hosting | [Vercel](https://vercel.com) (frontend) · [Railway](https://railway.app) (services) |
| Payments | [Stripe](https://stripe.com/docs) |
| Observability | [Sentry](https://sentry.io) · [PostHog](https://posthog.com) |
| Secrets | [Infisical](https://infisical.com) |
| Desktop | Swift · SwiftUI · AppKit |

See [TECH_STACK.md](../TECH_STACK.md) for a deeper architecture overview.
