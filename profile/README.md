## What is Ara?

Ara is an AI-powered coding assistant built for developers who want fast, context-aware help right inside their workflow. It understands your codebase, coordinates multi-step tasks with background agents, and surfaces results without getting in your way.

You're looking at the public GitHub presence for Ara — visit [github.com/Aradotso](https://github.com/Aradotso) to browse our open-source repositories, or head to [ara.so](https://www.ara.so) to try the product.

---

## How this page works

This repository is the special `.github` org-profile repo for the [Aradotso](https://github.com/Aradotso) GitHub organization. GitHub automatically renders `profile/README.md` as the public-facing banner you see at the top of the org page — no extra configuration needed. Editing this file and pushing to `main` is all it takes for the change to go live.

---

## Profile directory structure

```
profile/
├── README.md   ← this file; rendered as the org homepage on GitHub
├── hero.png    ← wide banner image shown at the top of the README
└── logo.png    ← square logo mark used inline in the README
```

`README.md` is the only file GitHub reads for the profile. The image assets are referenced from it by relative path, so they must live in the same `profile/` directory to render correctly.

## Contributing

1. Fork or clone this repo and create a branch.
2. Edit `profile/README.md` (and swap in updated images if needed).
3. Open a pull request against `main`. A preview is visible on GitHub once the PR is merged.

Keep the tone direct and the visuals crisp — this is often the first thing a developer sees when they land on the Ara org page.
