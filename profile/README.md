## Build automations that actually run

Ara is an agent-native workspace for power users, developers, and founders who want agents to do real computer work: understand a project, edit files, drive browsers and terminals, open reviewable changes, and learn the workflow for next time.

## What's Next

We are making Ara more transparent about where the product is going. The public direction is focused on self-driving agent loops, background coding agents, mission control, reusable skills, durable memory, and integrations with the tools builders already use.

Read the [Ara GitHub roadmap](../ROADMAP.md) for planned agent types, platform enhancements, integrations, and directional timelines. It complements the public product roadmap at [ara.so/roadmap](https://ara.so/roadmap).
