# Ara Public Roadmap

Ara is building the agent runtime for people who want software, operations, and research work to keep moving while they focus on higher-leverage decisions. This roadmap is a public snapshot for power users, developers, and founders evaluating where Ara is headed.

Until a canonical product board is published on [ara.so](https://ara.so), this GitHub profile roadmap shares the direction we are building toward.

## Now

These are the capabilities Ara is actively sharpening for early users.

- Background coding agents that work in isolated branches, commit their changes, push for review, and learn repeatable workflows as skills.
- Mac-native agent sessions that can use local context, project files, browser surfaces, and workspace state without requiring the user to babysit every step.
- Durable memory and skill capture so successful runs improve the next run instead of disappearing into chat history.
- Review-ready handoffs that make agent work easy to inspect, test, and merge.

## Planned agent types

Near-term work is focused on making Ara more useful across the full product-building loop.

- Product and growth agents for landing pages, launch assets, changelogs, customer research, analytics review, and weekly progress summaries.
- Developer agents for refactors, test expansion, dependency upgrades, issue triage, security review, and release preparation.
- Founder and operator agents for inbox follow-up, CRM hygiene, investor updates, recruiting loops, and lightweight back-office workflows.
- Better planning surfaces that show what an agent intends to do, what changed, what it learned, and what should happen next.
- Safer background execution with clearer sandbox boundaries, branch policies, audit trails, and human review checkpoints for sensitive actions.

## Platform enhancements

Ara's platform roadmap centers on reliability, transparency, and composability.

- A richer skill system for turning proven procedures into reusable agent playbooks across projects and teams.
- Stronger memory controls so users can inspect, edit, and scope what Ara remembers.
- Multi-agent workstreams that split research, implementation, validation, and review into coordinated background tasks.
- First-class evaluation loops for checking agent quality, regression risk, and task completion before work reaches a reviewer.
- More predictable runtime routing across local tools, cloud agents, browser context, and desktop automation.

## Integrations

Ara is prioritizing integrations that help agents close real loops rather than only draft suggestions.

- Source control and review systems such as GitHub for branches, pull requests, code review, and release handoffs.
- Product systems such as Linear, Slack, Notion, and email for context gathering, status updates, and follow-through.
- Developer platforms such as Vercel, Railway, Supabase, Sentry, PostHog, Stripe, and CI providers for deploy-aware automation.
- Knowledge sources such as docs, browser sessions, local files, and team memory so agents can ground their work in current context.

## Timelines

Roadmap timing is intentionally shared as horizons instead of fixed launch dates because Ara is learning from real agent runs.

- Current: background coding, memory, skills, Mac workspace context, and reviewable GitHub handoffs.
- Next 1-2 months: deeper product-building agents, clearer run reports, stronger skill reuse, and more reliable background task orchestration.
- Next 3-6 months: broader app integrations, team memory controls, multi-agent workflows, and richer evaluation gates.
- Later: an agent marketplace and shared playbooks for common startup, developer, and operations workflows.

## What we optimize for

- Agents that do useful work end-to-end, not just generate plans.
- Transparent changes that users can inspect, test, and trust.
- Tight learning loops where each successful run becomes a better future workflow.
- Practical automation for builders who want momentum without giving up control.
