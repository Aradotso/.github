# Contributing to Ara

Thank you for your interest in Ara! We welcome feedback, bug reports, and contributions.

## Community

For questions about Ara, troubleshooting, or feature requests, join our community at:

- **GitHub Discussions**: [github.com/Aradotso/.github/discussions](https://github.com/Aradotso/.github/discussions)
  - Use this for questions, ideas, and general discussion.
  - Open a new discussion under the appropriate category (Q&A, Ideas, etc.).
- **Email support**: [support@ara.so](mailto:support@ara.so)
- **Website**: [ara.so](https://www.ara.so)

> If GitHub Discussions is not yet enabled for this org, please open an issue or email us to request it — we'll set it up promptly.

## Reporting Bugs

Open an issue in the relevant repository. Include steps to reproduce, expected behavior, and your Ara version.

## Feature Requests

Post in [GitHub Discussions → Ideas](https://github.com/Aradotso/.github/discussions) so the community can weigh in before we prioritize it.

## Pull Requests

1. Fork the relevant repository and create a branch from `main`.
2. Make your changes with clear commit messages.
3. Open a pull request describing what you changed and why.
4. A maintainer will review and merge or provide feedback.

We look forward to hearing from you!
