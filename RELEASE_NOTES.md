# Release notes

## v0.1.0

This first Ara organization profile baseline release packages the public governance materials that downstream repositories can reference while Ara confirms readiness for broader adoption.

Included in this baseline:

- Organization profile README with Ara hero and logo assets
- Security reporting policy
- Contribution guidelines
- Code of conduct
- MIT license for repository text and documentation
- Legal notes covering trademarks, branding, and downstream adoption
- CODEOWNERS baseline for organization profile and governance files

This release should remain draft/pre-release until Ara confirms the governance baseline is ready for external use.
