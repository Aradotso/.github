# Security Policy

Ara takes security seriously. This repository is the public organization profile and governance baseline for Ara-owned open source projects.

## Reporting a vulnerability

Please do not open a public GitHub issue for suspected vulnerabilities.

Email security reports to security@ara.so with:

- Affected repository or asset
- A clear description of the issue
- Steps to reproduce, if available
- Potential impact
- Any relevant proof of concept or screenshots

We will acknowledge reports as quickly as possible and coordinate remediation privately before public disclosure when needed.

## Supported scope

This baseline covers organization-level community, legal, security, branding, and ownership files. Product-specific security support windows should be documented in each product repository.

## Coordinated disclosure

Ara asks reporters to give us reasonable time to investigate and remediate confirmed issues before publishing details. We will credit reporters when requested and appropriate.
