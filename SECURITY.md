# Security Policy

## Reporting security issues

Please report security concerns for this GitHub organization profile repository to founders@ara.so. Include a clear description, the affected file or GitHub profile surface, reproduction steps, and any suggested impact or remediation.

Ara also publishes security contact information at https://ara.so/.well-known/security.txt. Use the contact above for issues specific to this repository; for issues involving Ara's products, applications, infrastructure, or customer data, follow the channels listed in Ara's published security contact information instead.

## Scope

This policy applies only to this GitHub organization profile repository and the public GitHub profile content it controls, such as profile copy, profile images, community health files, and repository metadata maintained here.

This policy does not cover the Ara app, Ara services, production infrastructure, customer workspaces, authentication systems, payment flows, or other Ara-owned repositories unless those assets explicitly link back to this policy.

## Responsible disclosure timeline

Ara asks researchers to give us up to 90 days to investigate and remediate a validated issue before public disclosure. We will try to acknowledge reports within 7 calendar days, provide status updates when there is meaningful progress, and coordinate a disclosure date once a fix is available or the 90-day window has elapsed.

If a report describes active exploitation, exposed secrets, or a credible risk to users, please make that clear in the initial email so we can prioritize the response.

## Bug bounty and escalation

We did not identify a public Ara HackerOne or formal bug bounty page that is clearly tied to this GitHub organization profile. Reports for this repository are therefore not eligible for an implied bounty unless Ara separately confirms otherwise in writing.

If Ara later publishes a formal bug bounty or HackerOne program, researchers should use that program for serious security issues and mention this repository when the finding relates to the GitHub organization profile.

## Out of scope

The following testing and reports are out of scope for this repository:

- Social engineering, phishing, or physical attacks against Ara employees, contractors, customers, or partners.
- Denial-of-service, volumetric, resource-exhaustion, or stress testing.
- Automated vulnerability scans that create excessive traffic or noisy alerts.
- Attempts to access, modify, delete, or exfiltrate data that does not belong to you.
- Issues requiring compromise of a user's device, browser, GitHub account, email account, or third-party service.
- Reports about Ara products, services, infrastructure, or applications that are unrelated to this GitHub organization profile repository.
- Missing security headers, TLS configuration findings, or generic best-practice reports for domains or services not maintained by this repository.

Please act in good faith, avoid privacy violations and service disruption, and stop testing as soon as you confirm a potential issue.
