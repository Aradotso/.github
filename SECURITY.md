# Security Policy

We take security seriously at Aradotso. This document outlines how to report security vulnerabilities and our commitment to maintaining a secure agent-building platform.

## Supported Versions

We actively support and apply security patches to the following versions of Ara and related packages:

| Version | Supported |
| ------- | --------- |
| Current Stable | :white_check_mark: |
| < Current Stable | :x: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within Ara, please do not report it publicly through issues or pull requests. Instead, report it responsibly:

- **Email**: Send detailed vulnerability reports to [security@ara.so](mailto:security@ara.so).
- **Details**: Include a description of the vulnerability, steps to reproduce, and any potential impact or proof-of-concept.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to coordinate a security release.
