## About

This `.github` repository holds the shared community health files for the Aradotso GitHub org: org profile, contributing guidelines, issue/PR templates, and the project roadmap.

## Roadmap

See [ROADMAP.md](./ROADMAP.md) for short-term wins (next 30 days), medium-term goals (60–90 days), and the long-term vision (6+ months). Items are prioritized toward reducing friction for external contributors and improving org discoverability.

## Contributing
