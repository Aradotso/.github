# Aradotso .github Repository

This repository is the organization-wide `.github` configuration repository for the **Aradotso** (Ara) organization on GitHub. 

## Purpose

The primary purpose of this repository is to manage the public-facing organization profile, brand assets, and shared community configuration templates for Aradotso repositories.

- **Organization Profile**: The markdown and assets located in the `profile/` directory define the landing page for [github.com/Aradotso](https://github.com/Aradotso).
- **Brand Assets**: Houses official logos, hero graphics, and banners used across organization documentation.
- **Shared Templates**: Reserved for organization-wide issue templates, pull request templates, and workflow configurations in the future.

## Directory Structure

```text
.
├── profile/
│   ├── README.md     # The public profile markdown displayed on github.com/Aradotso
│   ├── logo.png      # Official Ara logo asset
│   └── hero.png      # Profile hero image
└── README.md         # This repository overview
```

## Making Changes

To update the public organization profile:

1. Create a branch and modify the files under `profile/`.
2. Keep brand assets clean and optimized in standard web formats (`.png`, `.svg`).
3. Commit and push the branch to open a pull request. Once merged to `main`, updates will propagate live to the Aradotso GitHub organization profile.
