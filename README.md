# Ara — `.github` org profile

This repository holds the public GitHub organisation profile for [Ara](https://ara.so) and the canonical brand guidelines.

`profile/` contains the GitHub org profile README (rendered at [github.com/Aradotso](https://github.com/Aradotso)) along with the hero and logo images displayed there.

`branding/` contains the full brand reference: multi-size logo exports, color palette, typography choices, spacing system, and usage rules. See [branding/BRAND_GUIDELINES.md](./branding/BRAND_GUIDELINES.md) for details.

## Logo assets

Pre-exported PNGs live in `branding/logos/`:

- `ara-logo-16x16.png` — favicon / tiny icon slots
- `ara-logo-32x32.png` — app icon / toolbar
- `ara-logo-64x64.png` — notification / thumbnail
- `ara-logo-256x256.png` — macOS bundle / marketing
- `ara-logo-512x512.png` — App Store / high-res print

The master source is `profile/logo.png` (512×512 RGBA PNG).

## Brand at a glance

Primary colors: `#0D0D0D` (Ara Black), `#FFFFFF` (Ara White), `#525252` (Ara Charcoal), `#8AAFC0` (Slate Blue accent).

Primary typeface: [Geist Sans](https://vercel.com/font) with Geist Mono for code.

Full details → [branding/BRAND_GUIDELINES.md](./branding/BRAND_GUIDELINES.md)
