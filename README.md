# Aradotso/.github

This is the GitHub org profile repository for [Ara](https://ara.so) (`Aradotso`). It controls the public-facing presence of the organization on GitHub.

## What lives here

**`profile/`** — Public org profile assets rendered on the [Aradotso GitHub page](https://github.com/Aradotso). This includes the hero image, logo, and the profile README that GitHub displays automatically. See [`profile/README.md`](./profile/README.md) for the visual content.

**`.github/`** _(planned)_ — Org-wide workflow templates, issue templates, and pull request templates will live here when added. These apply as defaults across all repositories in the organization that do not define their own.

## Contributing

To update the org profile:

1. Fork or branch from `main`.
2. Edit files inside `profile/` — the README, hero image (`profile/hero.png`), or logo (`profile/logo.png`).
3. Open a pull request against `main` with a short description of what changed.
4. A maintainer will review and merge. Changes go live on the GitHub org page within minutes of merging.

To add org-wide templates or workflows, create the relevant files under `.github/` (e.g. `.github/ISSUE_TEMPLATE/`, `.github/workflows/`) and open a PR as above.
