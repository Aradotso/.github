# Ara Organization Profile

This repository contains the public branding assets and profile layout for the [Ara](https://github.com/Aradotso) organization on GitHub. It automatically syncs to github.com/Aradotso.

## Structure

- `profile/`: Contains the public assets (such as `hero.png` and `logo.png`) and the primary `profile/README.md` which is displayed on the organization's public landing page.
- `.github/`: If added in the future, this directory will contain organization-wide workflows, templates, or issue configurations.

## How to Update

To update the organization profile or its assets:

1. Modify or add branding assets within the `profile/` directory.
2. Edit `profile/README.md` to update the displayed markdown profile content.
3. Commit and push your changes to `main` (or submit a pull request) to deploy the updates live.

Refer to the official [GitHub special .github repository documentation](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile) for more information.
