# Aradotso/.github

This is the [GitHub org profile repository](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile) for [Aradotso](https://github.com/Aradotso).

The `profile/README.md` file is automatically rendered on the [Aradotso org page](https://github.com/Aradotso) on GitHub. This repository also carries the first Ara organization foundation baseline so downstream repositories can reference one stable release for shared governance expectations.

## Foundation baseline

Release `v0.1.0` covers:

- `profile/README.md`, `profile/hero.png`, and `profile/logo.png` for the public organization profile and brand presentation.
- `SECURITY.md` for responsible disclosure and supported-version expectations.
- `CONTRIBUTING.md` for contribution flow, commit conventions, changelog expectations, and review requirements.
- `CODE_OF_CONDUCT.md` for community standards and enforcement contact.
- `LICENSE` and `LEGAL.md` for proprietary licensing, trademark, privacy, and contact guidance.
- `.github/CODEOWNERS` for founder ownership of the profile and governance files.

## Structure

```
.github/
  CODEOWNERS       ← review ownership for governance/profile files
profile/
  README.md        ← rendered on the Aradotso org page
  hero.png         ← header banner image
  logo.png         ← secondary logo
README.md          ← repository overview
CONTRIBUTING.md    ← how to contribute to Ara projects
SECURITY.md        ← vulnerability reporting policy
CODE_OF_CONDUCT.md ← community standards
LEGAL.md           ← legal and licensing overview
LICENSE            ← proprietary license baseline
CHANGELOG.md       ← release history
```

## Updating the profile

Edit `profile/README.md` and open a PR against `main`. The change goes live as soon as it merges — no deploy step needed.
