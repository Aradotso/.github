# Aradotso/.github

This is the GitHub org profile repository for [Ara](https://ara.so) (`Aradotso`). GitHub uses special files in this repo to customize how the organization appears publicly and how contributors interact with it across all Ara repos.

## What's in here

**`profile/`** — Public-facing org profile assets rendered on the [Aradotso GitHub page](https://github.com/Aradotso). Contains the org profile `README.md` and supporting images (hero banner, logo). See [profile/README.md](./profile/README.md) for the visual content shown to visitors.

**`.github/` (planned)** — Org-wide workflow templates and reusable actions will live here. Issue and pull request templates placed here are inherited by every repo in the org that doesn't define its own.

**Community health files (planned)** — `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, and `SECURITY.md` at the repo root are automatically surfaced by GitHub across all Aradotso repositories.

## How to update the org profile

1. Edit `profile/README.md` for text or layout changes.
2. Replace `profile/hero.png` or `profile/logo.png` to update imagery (keep filenames the same so existing references don't break).
3. Open a pull request against `main`. Changes go live on the org page as soon as the PR is merged.
