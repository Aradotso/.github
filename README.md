# Ara Organization Profile

This repository (`Aradotso/.github`) is the public GitHub profile and shared community resources for the [Ara](https://github.com/Aradotso) organization.

## What's Here

- `profile/` — assets and README displayed on the Ara GitHub org landing page
- `branding/` — canonical logo set, color tokens, typography, and brand style guide
- `SECURITY.md` — responsible disclosure policy for all Aradotso-maintained repos
- `CODE_OF_CONDUCT.md` — community standards (Contributor Covenant v2.1)
- `CONTRIBUTING.md` — contribution guidelines for org-level tooling and profile changes
- `CHANGELOG.md` — record of notable changes to org-level files

## How to Update the Profile

1. Edit `profile/README.md` and/or swap assets in `profile/` (hero.png, logo-light.png, logo-dark.png).
2. Open a PR against `main`. Changes go live automatically once merged — GitHub reads `profile/README.md` directly.
3. Update `CHANGELOG.md` under `[Unreleased]` with a summary of the change.

See the [GitHub docs](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile) for more on org profile customization.
