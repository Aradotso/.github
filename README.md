# Ara (ara.so)

Ara is an agent-building agent for Mac. It runs on your desktop, controls your apps, and builds and runs automated agents that learn over time.

This is the public GitHub organization for Ara. It hosts open-source components, starter kits, and example agents built by the Ara team.

## What is Ara?

Ara lives in your Mac's notch. It can:

- Control your Mac (keyboard, mouse, screen) to automate any desktop workflow
- Browse the web, read and write files, run terminal commands
- Build recurring or one-shot agents that run in the background
- Remember useful facts across sessions and get smarter with each run
- Connect to third-party apps (Linear, Slack, Supabase, Stripe, and more) via plugins

You write a goal in plain English. Ara figures out the steps, executes them, and reports back.

## Getting started with Ara

1. Download Ara from [ara.so](https://www.ara.so)
2. Install it on your Mac (macOS 14 Sonoma or later)
3. Open the notch widget and say what you want to automate

No API keys, no config files, no terminal commands required to get started.

## Building agents

Ara agents are goal-driven. You describe what you want, Ara runs it:

```
"Every morning, summarize my unread emails and post a digest to Slack"
"When a Linear issue is marked Done, close the linked GitHub PR"
"Watch this folder and upload any new PDFs to my Notion database"
```

Agents can be one-shot (run now) or recurring (run on a schedule). Ara saves what worked and improves each run automatically.
