# amp — Aradotso Organization Profile

## What is amp?

amp is the public organization profile repository for [Aradotso on GitHub](https://github.com/Aradotso). It powers the branding and description shown at the top of the org page.

The `profile/` directory is rendered directly by GitHub at https://github.com/Aradotso and contains the org's hero image, logo, and description — effectively the front door of the Ara open-source presence.

The `.github/workflows/` and `scripts/` directories (added as the org grows) hold CI and validation tooling that keeps profile content fresh and consistent.

amp is maintained by the Ara team. For questions or contributions, visit [ara.so](https://ara.so) or open an issue in this repo.
