# Aradotso/.github

This is the GitHub organization profile repository for [Ara](https://www.ara.so) (`Aradotso`). It controls what visitors see when they land on the organization's GitHub page and serves as the home for shared org-level configuration.

## What's in this repo

**`profile/`** — Public-facing org profile assets rendered on the Aradotso GitHub page. Contains the profile `README.md` (the banner, logo, and website link that GitHub displays) along with any accompanying images (`hero.png`, `logo.png`). See [`profile/README.md`](./profile/README.md) for the rendered content.

**`.github/`** (planned) — Org-wide GitHub Actions workflows and reusable workflow templates will live here when added. Issue templates, pull request templates, and `CODEOWNERS` files for shared defaults across all repos in the org will go here as well.

## How to update the org profile

1. Edit `profile/README.md` to change the text, links, or layout shown on the Aradotso GitHub page.
2. Replace or update `profile/hero.png` and `profile/logo.png` to change the visual assets.
3. Open a pull request against `main`. Changes go live as soon as the PR is merged — no deployment step needed.

## Contributing

Keep the profile clean and on-brand. For significant visual changes, drop a screenshot in the PR description so reviewers can see the before/after. For adding org-wide workflows or issue templates, create them under `.github/` and document them here.
